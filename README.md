## About

I’m building LocalHouseLLM to make AI more local, modular, and user-owned.

My focus is on the systems layer: models, protocols, orchestration, memory, and tools working together as a unified stack rather than disconnected components.

## Core systems

- **AICL** — adaptive communication for AI modules
- **ORCHA** — orchestration runtime and model coordination
- **Nomi** — local-first memory and identity infrastructure
- **Anvira** — AI workspace for long-horizon work on edge hardware

## Stack

**Languages** — Python · TypeScript · React · FastAPI

**AI & systems** — llama.cpp · GGUF · Model orchestration · Local inference · AI systems design
